Створи сторінку для Kadr — Android-віджета з програмованим статичним контентом.
Поверни лише один повний HTML-документ, без Markdown-огорож і пояснень. CSS та JavaScript розмісти всередині. Використовуй звичайний JavaScript або включений Vue. Побудуй компактну читабельну композицію без скролу та анімацій. Дотримуйся контракту Kadr SDK нижче, підтримай світлу й темну теми та виклич Kadr.ready() лише після готовності даних і вмісту. Обробляй помилки fetch/JavaScript через Kadr.fail(message). Не додавай у HTML нативну кнопку оновлення та час останнього успіху.
