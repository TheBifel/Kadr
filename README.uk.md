# Kadr

**Твої дані. Твоя композиція. Один Android-віджет.**

Kadr перетворює HTML-сторінку з CSS і JavaScript на віджет домашнього екрана. Сторінка сама отримує дані з API, обробляє їх і малює композицію. Застосунок зберігає кадр, закриває рушій і показує результат до наступного успішного оновлення.

## Яку проблему він вирішує

Потрібна інформація часто вже є в API, але застосунок не має віджета або показує його в незручному вигляді. Писати окремий Android-застосунок для кожного невеликого дашборда складно. А статичне зображення чи JSON-файл усе одно хтось має оновлювати.

У Kadr контент програмований: дані оновлює сама сторінка. Можна написати її самостійно або скопіювати вбудовані ШІ-інструкції й згенерувати. Приклади: відключення світла, погода, транспорт, статус сервісів і графіки власного API. Сервер або обліковий запис Kadr не потрібен.

## Як користуватися

1. У меню віджетів створи проєкт і встав HTML/CSS/JavaScript або імпортуй файл. Шаблони, ШІ-інструкції та довідка — у боковому меню зліва, доступному свайпом.
2. Онови прев’ю його кнопкою ↻, потім натисни «Зберегти». Перегляд не змінює домашній віджет.
3. Назва, тема й розклад — у секції «Налаштування віджета». Після збереження натисни «Додати на домашній екран».
4. Натискання кадру відкриває редактор, ↻ оновлює його у фоні.

Якщо прев’ю завершилося помилкою, поруч з індикатором з’являється кнопка копіювання діагностики: початкова причина, стек, розміри макета та події WebView. Вона доступна без розгортання деталей і зникає після усунення помилки.

Кадр зберігається після мережевих помилок і відновлюється після ребуту та розблокування. Мова системна, назва Kadr не перекладається. ШІ-інструкції копіюються лише англійською. Час і кнопка розміщені поверх HTML у нижньому правому кутку; відступ під них визначає сама сторінка.
